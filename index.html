Noun Project API Settings

To display real SVG icons from The Noun Project, you need an API key and secret. Get a free API key here (no credit card required for 30 days).

⚠️ Security Warning: Credentials are stored in your browser and exposed in the page source. Only use this for personal projects on your own computer. Never share your credentials or use in production.

ℹ️ CORS Note: The Noun Project API may block direct browser requests. If API calls fail, enable a CORS proxy in the code or use a browser extension for testing.
